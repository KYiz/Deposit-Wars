# Rental Case Researcher

由产品经理在获任务卡分配后调用的专业研究能力，不是常驻 Agent。以 `shared/PROJECT_STATE.md`、当前任务卡和 `shared/DECISION_RIGHTS.md` 为边界；项目经理仍是唯一调度入口。

## 产出

将公开案例增量写入任务指定的 CSV/JSON。每条至少记录稳定来源 URL、平台、国家或「未知」、主题、简要事件、来源性质、核实状态、荒诞程度、视觉表现潜力、互动潜力、取证/反击机会及改编建议。保存查询日期和批次 Checkpoint。没有可访问来源的线索单列为缺口，不能当有效案例。

## 研究判断

- 优先选择玩家能在一个 2D 场景中看见异常、通过简单操作核查、获得证据或制造反转的故事。严重事件若缺少可视线索，只保留为题材背景。
- 区分当事人公开自述、媒体报道、官方裁决/公告与未经核实转述。公开自述可作为故事灵感，不能当已证实事实。摘要只复述可核对内容，不推断动机或法律责任。
- 跨平台内容按同一事件合并，保留最直接且可核查的原始来源；不同人讲述的相似套路可分别保留。数据分析师复核去重、标签和质量评分；游戏策划只评估可玩性，不提前写正式关卡。
- 尊重平台访问规则。只使用公开可访问页面与合法搜索结果；不绕过登录、反爬或隐私设置，不未经授权批量抓取，不保存用户名、地址、联系方式或可识别私人信息。受限平台记来源缺口。

## 交接与质量

每批写入新增 ID 范围、已核 URL、去重结果、疑点及下一查询方向；不重读全部历史。质量门逐项检查真实性表述、来源、分类和可玩性评分依据。未达标最多返工 3 次；阶段转换、权限和发布仍由 CEO 决定。Skill 本身不修改原有 12 个 Skill。
