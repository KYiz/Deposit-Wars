# 双视角找茬 Demo｜CASE FILE 首屏 UI Skill

## 目标

为「一间好房，两份真相」双视角找茬游戏设计进入玩法前的独立身份选择界面（CASE FILE）。

此首屏负责建立案件背景、呈现两种立场并让玩家选择身份。玩家选择“我是租客”或“我是房东”后，再进入独立的房间调查界面。首屏不应同时承担实际调查 HUD、线索破解进度或答题弹窗等游戏内功能。

这是当前 Demo 的设计提案，待 CEO 评价；不是已冻结的 V1 规范。

## 核心体验

- **先立场，后调查：** 让玩家先理解自己将以谁的视角看待这间房。
- **同一案件，两种解释：** 租客寻找广告与现场的矛盾；房东识别问题并选择实际整改方式。
- **首屏保持聚焦：** 只展示案件引言、角色选择与进入现场提示，不提前泄露三个线索的答案。
- **两种身份平等：** 租客与房东卡片大小、视觉权重和交互层级一致。
- **视觉风格统一：** 沿用几何拼接房间、漫画式硬边框、暖纸色和珊瑚红强调色。

## 建议文案

- 品牌标题：`一间好房，两份真相`
- 案件标签：`CASE FILE · 海景公寓 · 301室`
- 主标题：`一间好房，两份真相`
- 副标题：`同一间房，你会相信谁？`
- 案件引言：`关于这间房的描述，租客和房东各执一词。同一间房，同样的画面，不同的立场，不同的真相。`
- 租客角色：`我是租客`
- 租客目标：`找出广告与现场的矛盾，追回押金。`
- 房东角色：`我是房东`
- 房东目标：`发现问题并整改，避免风险。`
- 主按钮：`选择身份后进入现场`
- 辅助提示：`选择身份后即可开始调查`

所有金额、案件和角色陈述均为虚构游戏内容，不构成现实租赁建议或真实案件陈述。

## 页面结构

1. **顶部品牌栏**
   - DW 标志
   - `一间好房，两份真相`
   - `PLAYABLE DEMO`
2. **案件标签**
   - `CASE FILE`
   - `海景公寓 · 301室`
3. **案件叙事区**
   - 主标题、副标题和一段简短案件引言
   - 可用公寓外观照片式插画、房间缩略图、档案纸张等作为装饰
4. **身份选择区**
   - 租客卡：浅绿底，租客人物插画，目标描述
   - 房东卡：浅橘底，房东人物插画，目标描述
   - 两张卡等大、同等显著；选中状态应清晰
5. **底部行动区**
   - 选择身份后进入现场的主按钮
   - 未选身份时，按钮应禁用或点击后给出明确提示

## 视觉规范

| 元素 | 规范 |
|---|---|
| 页面底色 | 暖纸色 `#f4f0e7` |
| 主要文字与边框 | 深墨紫 `#22243b` |
| 强调色 | 珊瑚红 `#d96762` |
| 租客角色卡 | 浅鼠尾草绿系 |
| 房东角色卡 | 浅橘色系 |
| 线条 | 粗描边、清晰分隔、硬阴影，带漫画纸卡质感 |
| 插画 | 原创几何拼接、扁平色块、略带编辑插画气质 |
| 字体 | 系统无衬线回退；优先 DM Sans、Noto Sans SC（若设备已有），否则 sans-serif |
| 字体加载 | Demo 不强制下载外部字体 |
| 整体气质 | 有趣、带一点悬疑、可读性优先，避免装饰压过角色选择 |

## 布局与响应式

- 桌面端优先采用编辑式分栏或中心化主面板；角色卡应位于视觉焦点区域。
- 页面容器建议最大宽度 `1600px`，两侧留白可采用 `clamp(20px, 4vw, 70px)`。
- 中等屏幕下压缩装饰元素与间距，保持两张角色卡的可读性。
- 小屏幕下可将角色卡并排或上下排列；以点击目标足够大、正文不拥挤为优先。
- 避免依赖极小字号传递案件关键信息。
- 图片是静态视觉稿；正式实现需要使用 HTML/CSS/TypeScript 建立真实布局与交互。

## 交互规则

1. 初始状态：未选身份；展示案件信息和两个角色选项。
2. 选择角色：角色卡进入明确选中状态，并更新当前身份。
3. 进入现场：只有已选择身份后才能继续。
4. 进入游戏：转到房间调查界面，并传入当前角色身份。
5. 返回或切换身份：允许回到 CASE FILE 更改角色。
6. 不应在 CASE FILE 首屏显示已破解线索、分数结算或调查答案。

## 可达性

- 角色卡必须是语义化按钮或可键盘操作的等价控件。
- 支持鼠标、触屏以及键盘 Tab/Enter/Space。
- 选中状态不能只靠颜色区分；同时使用边框、图标或文字标识。
- 提供可见焦点样式和足够的文字/背景对比度。
- 插画应有合适的替代文本；纯装饰图形使用空替代文本。
- 页面标题层级清楚，主按钮文案明确描述下一步动作。
- 小屏幕下确保点击区域足够大。

## 与游戏调查界面的边界

### CASE FILE 首屏负责
- 案件背景
- 身份选择
- 角色目标预览
- 进入现场

### 游戏调查界面负责
- 完整出租屋场景
- 01 帘子、02 墙画、03 时钟门锁热点
- 角色专属题干、选项和反馈
- 线索破解状态与进度
- 提示、分数、结局和重玩/切换视角
