进入角色后，CASE FILE 首屏隐藏；调查页不再有右侧档案栏或常驻线索清单。状态栏随租客/房东切换目标文案和身份色。进度圆点、热点破解颜色同步变化。答题和结局只在弹窗中出现；切换视角返回 CASE FILE，并清空该局进度。

## 画面实现

- 使用 CEO 提供的完整 UI 图像作为本地 Demo 场景素材。页面以 CSS 显示其中的房间区域，上方品牌和状态栏由真实 HTML 绘制，便于动态更新身份、目标和进度。
- 桌面房间保持整幅宽度，01/02/03 的语义化按钮对准帘子、墙画和右侧门锁；提示与切换按钮覆盖图中相同位置。
- ≤700px 时品牌和状态信息重新分行；房间完整缩放，不裁掉门锁；两个操作按钮移到图下方，保证触控区域。
- 主色沿用暖纸底 `#f4f0e7`、深墨紫 `#22243b`、珊瑚红 `#d96762`；租客状态绿、房东状态橘。
- 图片提供房间整体替代文字；热点和操作为原生按钮，焦点样式可见，进度使用 live region。弹窗保留 Tab 焦点循环和 Esc 关闭。
