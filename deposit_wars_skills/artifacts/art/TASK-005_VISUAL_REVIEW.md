# TASK-005 美术审核报告

版本 1.0｜2026-10-22｜状态：专业审核完成，等待 CEO 选择方向｜DRI：美术设计师；程序员仅协助实机采集。

## 1. 当前实际素材盘点

- **运行画面**：`../../../game/src/room.ts` 用 Phaser Graphics 矩形、圆、线与 Arial 文本实时绘制固定房间，五个热点状态随游戏状态重画；`../../../game/src/style.css` 绘制页眉、按钮、Inspection Phone、房东对话、证据卡与结算 UI。
- **独立资产**：`game/` 源码内没有房间背景 PNG、角色立绘、图集、原创字体或外部音频文件；基础音效是 `main.ts` 中 Web Audio 振荡器。也没有正式美术源文件/切图。原型形状与文字均为本项目自制占位表达。
- **实机证据**：`review/actual-desktop-page.png` 与 `review/actual-desktop-room-left.png` 为本轮 Chrome 本地运行截图；手机模拟 `review/actual-mobile-page.png`、`actual-mobile-room-left.png`、`actual-mobile-room-right.png`。完整预览及拍摄条件见 `TASK-005_SCENE_PREVIEW.md`。
- **美术缺口**：画面整体可辨，但偏正面平面剖面；当前编号和高亮框太明确，可能削弱找茬；D1、D2 首屏可见，D3–D5 需要横向查看；没有房东角色正式造型、统一资产规范或触屏实机视觉验证。

## 3. 6–8 房间 / 30–40 事件美术成本比较

这是**规划估算，不是实际工时、报价或 CEO 预算批准**。口径：首发 6–8 房间含 Sunny Side Studio；30–40 事件含首关五项；一名熟练 2D 美术的纯制作人日，包含场景底图、事件前后状态及共用 UI/角色/导出规范，未含程序、策划、外包采购、平台审核与大规模返工。假设每房间共用可复用构件，事件平均 2–3 个视觉状态。实测样本为零，范围应在首关正式资产试做后重估。

| 方案 | 共用规范/UI/角色 | 每房间场景 | 每事件视觉状态 | 6–8 房 + 30–40 事件合计粗估 | 相对成本 |
|---|---:|---:|---:|---:|---|
| A 精致斜视卡通 | 5–8 人日 | 3–5 人日 | 0.6–1 人日 | 41–88 人日 | 基准 1.0× |
| B 夸张手绘沙雕风 | 6–10 人日 | 5–8 人日 | 0.9–1.4 人日 | 63–130 人日 | 约 1.5×，逐房间构图/笔触更难复用 |
| C 独立游戏像素风 | 5–8 人日 | 4–6 人日 | 0.8–1.3 人日 | 53–108 人日 | 约 1.25×，状态/缩放/像素动画会抵消瓦片复用 |

上述合计未加排期缓冲；若要排开发排期，可先另加约 20% 审核及返工预留。6–8 房间、30–40 事件是 CEO **已定 V1 规划目标**，本轮未开始量产或扩展策划。

## 4. 推荐统一视觉规范（待 CEO 选定画风后锁定）

**推荐 A 作为 V1 基底**，允许在表情和 1–2 帧反应动作中借用 B 的夸张节奏，但最终线条、透视和色板只能有一套；不要把三个风格混在一间房。理由是 A 的区域分隔与热区轮廓更稳定，跨 6–8 房间更易复用，粗估制作成本最低。B 可作为高度风格化备选；C 适合 CEO 更看重独立游戏复古识别度时选择。选择仍由 CEO 决定。

- **角色**：房东保持原创、虚构的聊天头像/半身反应，主角不占据找茬画面；不复用真实案例人物形象。表情用 4 个基础口眼组合覆盖惊讶、狡辩、恼怒、败退。
- **场景**：固定一间房的剖面框架；若采 A，用单一约 10–15° 的地板斜视网格，墙面、门柜轴线一致；前/中/后景分层。每个事件提供待发现、检查后、取证后三个可独立开关的状态，避免把线索烙进背景。
- **UI**：Inspection Phone 是唯一工具。统一“现场事实—虚构广告承诺—证据卡—扣款卡”四类卡片；大按钮和强对比图形，文字为英语短句；场景提示不永久压住线索。触屏热区建议至少约 44×44 CSS px，须在实机验证。
- **颜色**：深海军蓝 `#173049` 承载主文本/轮廓，奶油色 `#F5E8CB` 作背景，青绿 `#6FA7A2` 作常态，珊瑚橙 `#E8A85A` 标互动，浅绿 `#60D4A5` 标已取证；“可疑/已完成”同时用形状和图标区分，不只靠颜色。色值是建议起点，待最终图集和对比度测试。
- **线条**：A 方案房间主要轮廓统一中等粗细，交互物外轮廓比背景约 1.5 倍；避免小屏细纹竞争。UI 轮廓与场景轮廓呼应，但按钮仍须像按钮。
- **动画**：事件关键动作各 2–4 帧或简单位移/旋转；揭露瞬间加入 0.2–0.4 秒停顿和房东夸张表情。所有信息在静帧仍能读懂；静音/减少动态时不丢线索。
- **交付规格草案**：以现有 960×540 逻辑房间为基准，先制作一房间的可编辑分层源文件、导出图集、状态清单及一张 390 CSS px 手机检查图，再估剩余房间。PNG 图集/字体授权与包体须在正式制作任务中检查。本轮不生成正式素材。
