# CASE FILE 独立选身份首屏｜UI 实现说明

版本 0.1｜2026-10-26｜TASK-009 本地 Demo 实现，**待 CEO 评价，不是正式 V1 视觉规范**。

入口：`game/perspective-demo.html`。参考：CEO 提供的档案夹式概念图，以及本地保存的 [`perspective-demo-case-file-proposal.md`](references/perspective-demo-case-file-proposal.md)。该文档中的文本按设计参考使用，未作为独立阶段门或发布授权。展示素材为 CEO 本轮提供的图像副本 `game/public/case-file-reference.png`；本轮没有调用图像生成或修改原图。

## 页面分工

```text
CASE FILE 首屏 → 选中租客/房东 → 点击进入现场 → 调查房间 → 结局
       ↑                                           │         │
       └────────────── 换个视角 / 通关后换身份 ─────┴─────────┘
```

- **首屏**只承担案件氛围、角色目标预览、选身份和进入现场。没有调查进度、01–03 热点、答题或结算。
- **调查页**保留 TASK-007 的抽象房间、三处谜点、角色专属问题、提示与结局。
- 原图中的“海景公寓 · 301室”是虚构案件名，不代表新增正式关卡或真实地址。

## 视觉与响应式

桌面以用户附图整幅呈现档案夹：暖纸、贴照片/地图/钥匙/平面图的拼贴、中央房间与两张同尺寸人物身份卡。真实 HTML 按钮覆盖图中两张角色卡和底部行动区，选中时出现珊瑚红轮廓与“✓ 已选择”。原图是装饰背景；案件标题、角色文本与按钮名称也在语义化 HTML 中，供辅助技术读取。

窄屏（≤700px）显示档案图上半段作预览，下面重排为原生 HTML 标题、两个大触控角色卡和行动按钮。文字不依赖缩小后的图像阅读；租客浅绿、房东浅橘，与桌面图的身份色对应。设计仍沿用 TASK-008 的 `#f4f0e7` 暖纸底、`#22243b` 深色描边、`#d96762` 珊瑚强调色。

## 状态与操作

| 状态 | 首屏反馈 | 下一步 |
|---|---|---|
| 未选择 | 两卡并列；“选择身份后进入现场”不可点击 | 选择一张卡 |
| 已选租客 | 租客卡有红色轮廓、标记；按钮可用 | 点击进入租客调查 |
| 已选房东 | 房东卡同等反馈；按钮可用 | 点击进入房东调查 |
| 从房间返回 | 回到 CASE FILE，清空该局进度与身份选择 | 可重新选角色 |
| 通关后换身份 | 回到 CASE FILE，并预选另一身份 | 点击进入现场 |

卡片是 `button`，使用 `aria-pressed` 表示选中。行动按钮在未选身份时使用原生 `disabled`。Tab/Enter/Space 可操作，焦点有明显轮廓。首屏主标题保留在 HTML 中，图片按装饰图处理。
