## 玩家能看到的改变

首关调查画面改为“底图揭露层 + 独立透明道具 PNG”：粉帘、装饰画、检查镜、柜门、门把、门牌、玻璃罩、蜡烛、擦拭布是各自的图片节点。拖动时移动整件 PNG，松手达阈值后前景物件消失，底图中预画的厕所、水痕、折叠床等随之露出；短拖回弹。旧版“截取整张背景作为拖动物件残影”的代码已移除。鼠标、触控和键盘路径均有本地测试。

`game/level-art-preview.html` 可从本地文件直接打开，按关卡与身份浏览 **6 张不同的房间场景、36 件主道具**，每关角色各看到 3 件并可拖动。它展示道具美术与图层手感，**不代表后五关的谜题、证据和结算已实现**。

逐事件清单见 [`TASK-017_PROP_ASSET_MAP.csv`](TASK-017_PROP_ASSET_MAP.csv)：每行保留 Case ID、故事物件、主 PNG、后续步 PNG、房间 PNG、预览锚点与尺寸、拖前/拖中/拖后状态、操作手势、虚构边界。个别复合物件（例如钟表门把）本身为一张道具 PNG；需要先后操作的照片、票据、阀门等已分别导出。交付给工程时必须按该表逐件挂载，不能用不可动的整幅底图代替。

## 图层与状态规范

1. `room.png`：每关环境底图；首关可玩房间使用 `room-underlayer.png`，其中仅预画被遮住的事实，玩家在前景移开前不应直接看见。主道具锚点与预览尺寸见 CSV，比例坐标以 1672×941 场景为基准。
2. 主物件 PNG：透明画布、清楚的外轮廓，置于线索前方；`pointerdown` 抓住的是 PNG 所在节点，拖动后只变换该节点。首关不再用 CSS 方块模拟帘、柜、门把；无 01–05 寻物圆圈。
3. 后续步 PNG：画内工具、记录纸或第二个遮挡物；每一步有独立可见状态。拖错回弹、成功保留揭露，最终才登记证据。键盘聚焦并 Enter 可执行等效动作。
4. 正式制作时按每事件输出 `before / dragging / after` 状态帧与可编辑源，修正图层对齐、碰撞范围和小屏视认。当前新关卡只完成物件与场景**草案**；除现有首关五处互动，后续事件的揭露层、遮挡逻辑和 Phone 证据均待制作。

## 来源、权利与性能

- 道具造型由项目案例目录的具体物件描述转译，案例 ID 与报道/自述边界见 TASK-016 事件目录和本任务资产表。没有复制案例网页照片、真实房屋或人物；它们是游戏虚构插画。
- 房间与物件草案使用 Codex 内置 imagegen 生成；首关揭露底图以项目已有 `investigation-clean.png` 为参考局部编辑，其来源原记录见 TASK-015。切图脚本只做技术分格，不改变物件造型。图集原件保留，未覆盖旧参考素材。
- 当前 PNG 以美术草案质量和透明图层验证为目标，未做手机实机、玩家可发现性、浏览器首屏加载与正式 PNG 压缩。离线首关单文件约 15.9 MB；正式网页发布前必须控制尺寸/加载并逐件检查锯齿、透明边缘和图层遮挡。六关预览中的部分道具是展示性摆放，并非正式谜题坐标。
