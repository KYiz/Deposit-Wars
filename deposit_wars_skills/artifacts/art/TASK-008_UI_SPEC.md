## 设计意图

画面是一张比例错位、几何形拼接的出租屋插画。帘子、装饰画、时钟门锁各有一个可辨的视觉矛盾；圆形 01–03 是明确可点的线索标记。租客与房东看同一张图，但问题和结局不同。所有金额、房间与角色陈述均是虚构游戏内容。

## 页面结构

```text
┌ 顶栏：DW 标志 / 一间好房*两份真相 / PLAYABLE DEMO ┐
│ 标题：这间房，你怎么看？       简短玩法说明         │
├───────────────────────────────┬────────────────────┤
│ 房间名 + 当前视角/进度         │ CASE FILE 档案      │
│                               │ 选角色 / 角色目标   │
│ 原创 SVG 房间 + 01–03 热点     │ 线索清单 + 进度     │
│                               │ 本局分数 / 换视角   │
│ 提示按钮                      │                    │
├───────────────────────────────┴────────────────────┤
│ 虚构内容说明                                       │
└────────────────────────────────────────────────────┘
```

桌面版的主画面与档案栏比例为“剩余宽度 : 325px”。页面容器最多 1600px；游戏框两侧留 `clamp(20px, 4vw, 70px)`。小于 950px 时档案栏移到画面下方；小于 590px 时进一步收紧字号、边距与热点编号，角色选择卡并排。房间 SVG 保持 1200×670 比例，窄屏按宽度缩放，不裁切右侧门锁。

## 视觉语言

| 元素 | 当前实现 |
|---|---|
| 页面底色 | 暖纸色 `#f4f0e7`，减少房间色块与背景的混淆 |
| 文字/边框 | 深墨紫 `#22243b` / `#24243f`；粗框、硬阴影表现漫画纸卡 |
| 重点色 | 珊瑚红约 `#d96762`，用于标题、状态、提示和结算 |
| 房间 | 鼠尾草绿墙、橘色地面、粉红帘、黄褐门；大色块和错位线条形成抽象感 |
| 角色卡 | 租客浅绿、房东浅橘；保持相同大小和入口层级 |
| 字体 | 系统无衬线回退：`DM Sans`、`Noto Sans SC` 若设备已有，其余使用 `sans-serif`；Demo 不下载外部字体 |
| 线索热点 | 深色圆形编号、浅色外圈；悬停/键盘焦点有轮廓反馈，破解后转绿 |

SVG 为项目内原创代码绘制，不含第三方图像素材。现阶段没有正式资产图集、动画或品牌字体授权结论。

## 交互流程与文案状态

1. 初始：画面可预览，右栏选择“我是租客”或“我是房东”。未选身份点击热点，会提示先选身份。
2. 选择身份：右栏切为角色目标、`0/3` 进度、三个线索条目和分数框。租客分数是虚构 `$0 / $300`；房东分数是 `0 / 3 项整改`。
3. 点击 01 帘子、02 墙画或 03 时钟锁：弹出观察句、一个看图问题和两个选项。三处可任意顺序调查。
4. 错误选项：该选项变淡并禁用，弹窗内给“再看一眼”的反馈；正确选项仍可点击，不扣分。
5. 正确选项：显示对应现场/广告矛盾或整改依据；右栏线索标“已破解”，热点转绿，本局计数加 1。
6. 三处均破解：进入结局弹窗。租客看到 `$300` 游戏押金追回；房东看到 `3/3` 问题整改。可换视角或同视角重玩。
7. “给我一点提示”：定位到第一个未破解热点，并显示位置提示；所有线索已解时再次打开结局。

租客路线：识破“独立卫浴 / 原有渗水 / 随时出入”的广告矛盾。房东路线：找出对应的宣传、维修和出入条件漏洞，选能实际整改的做法。两条路线共用场景，但题干、选项、反馈和结局不同。

## 输入与基础可达性

- 所有角色卡、热点、答案、提示和重玩均为 HTML 按钮，可用鼠标、触屏或 Tab/Enter 操作；`Esc` 可关闭弹窗。
- 弹窗有 `role="dialog"`、标题关联和 Tab 焦点循环，关闭后焦点回到触发元素；答案反馈区有 `aria-live="polite"`。
- 热点提供文字 `aria-label`，画面 SVG 提供整体描述；不要求玩家精确点图中极小物件。
- 390×844 模拟触屏已通过基本点击与提示测试。实体手机、屏幕阅读器实测、色弱检查及 Safari/Firefox 尚未执行。

## 待 CEO 评价

- 抽象程度：几何房间和硬边框是否符合想要的“脑洞在线找茬”。
- 双视角差异：房东线目前是“自查并整改”，是否要更偏对抗、经营或反讽。
- 谜题密度：三处、每处二选一仅用于快速展示；不代表正式关卡难度或 V1 事件规模。
