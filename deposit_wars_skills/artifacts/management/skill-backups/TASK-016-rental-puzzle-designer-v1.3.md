# Rental Puzzle Designer / 租房案例玩法转译

用于把 `artifacts/research/rental_cases.csv` 中的案例母题转为单房间、短局、双视角可玩的动作。先读取当前任务卡、`shared/PROJECT_STATE.md` 和游戏策划岗位 Skill；只按任务所需读取案例行及源文核查记录。项目经理仍是任务调度入口，游戏策划仍是玩法 DRI。

## 转译方法

1. 区分来源事实、受访者自述、游戏虚构设定。每条游戏事件保留 Case ID、原来源 URL、查询日期和改编边界；不把虚构合成房间称为真实案件。
2. 从案例中提炼一个玩家能在房间图上看见的异常信号，例如水痕、额外拖鞋、反常门把。信号应在拖动前出现，不能靠旁白直接给答案。
3. 指定要移动或组合的物件、拖动目标、揭露后的画面变化；多步检查各有不同的发现。拖错能复位，触控与键盘有等效路径，动作完成前不能记证据。
4. 写清租客与房东各自为何调查、看到同一事实后如何作答。租客保存现场反驳虚构扣款；房东识别错误宣传或不合理扣款并整改。不同视角不改变客观证据。
5. 最后才连到 Inspection Phone 的广告/现场对照、证据卡、扣款卡与结算。每张证据只解决一项指控；不输出真实法律判断。

交付一张可实现的谜题卡：`Case ID → 事实与改编边界 → 预告线索 → 物件/目标/操作 → 揭露画面 → Phone 证据 → 双视角反馈 → 失败补救 → 测试步骤`。没有可靠来源的内容标虚构或待核实，不杜撰来源。

首关实例和来源映射见 `artifacts/design/TASK-014_DRAG_PUZZLES.md`。本 Skill 不改变 `shared/WORKFLOW.md`、`shared/DECISION_RIGHTS.md`、原岗位 Skill 的权限，也不授权 G3、扩关或发布。
