## 物品栏状态机

1. 物品栏框架在桌面始终 `602×106 CSS px`，移动端以相同可用宽度响应式显示；**同一设备上切关不改变外框长宽**。内部固定六列，单格尺寸相同。开放格数为 `2, 2, 3, 3, 4, 4, 5, 5, 6`，其余格显示封条纹理而不删除列。
2. 每个身份每关有两处真实可标注问题。总开放格数等于该路线需要收集的物件数：第 1–2 关每问题 1 件；之后逐步发展到 2–3 件。房间另有一件与当前视角无关的干扰物，拿起时回弹并提示，不占格。
3. 玩家可拖动 PNG，也可点按拾取；正确物件从房间消失、加入第一个空格。重复拾取不计数；容量满不再放入。物品栏卡可选中/取消；键盘聚焦后 Enter 等效，Escape 取消选择。
4. 选中线索后，玩家点击房间里的实际问题区域。只有**线索属于该问题，且该问题所需物件均已收齐**，才留下红色手绘圈并计 `1/2`。错物件、错区域、未收齐时不计分、不扣押金，给简短反馈。标过的区域不能重复计分。
5. 两处均正确标注后显示完成并解锁“下一关”。九关按钮可自由预览，已完成的关卡在当前会话保留 ✓；切换租客/房东保留各自进度。重新挑战只清该关该身份状态。

## 画面与公平性

场景本身没有 01–05 寻物圆圈。可拖道具是独立透明 PNG；标注区在未选择物品时不画框，玩家需要从场景及物件位置推断，正确后才出现手绘圈。物品栏、角色切换与进度位于场景外边缘，减少遮挡。手机可横向查看房间，物品栏留在当前视口宽度内。

当前 `nine-level-demo.html` 已实现九关拾取/干扰/物品栏/标注/通关状态，可本地离线玩两视角；它还不是全部故事关卡：2–9 关的每一处隐藏问题揭露帧、Inspection Phone、押金结算和玩家实测尚未完成。物件与标注区的摆放是美术/操作样板，正式制作前需逐关按画面语义重校。
