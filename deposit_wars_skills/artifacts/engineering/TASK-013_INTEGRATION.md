## 实现范围

CASE FILE 保持租客/房东选择，调查画面继续共用 TASK-011/012 的房间画风。底层直接使用既有 [`GameSession`](../../../game/src/model.ts) 与 [`DEFECTS`](../../../game/src/content.ts)，新界面代码在 [`perspective-demo.ts`](../../../game/src/perspective-demo.ts)。因此 D1–D5 的检查步骤数、取证前置条件、证据配对、错配不扣钱、部分结算后回房保留进度和 `$500` 结算与旧 G2 一致。

| 旧玩法 | 新 Demo 入口与反馈 |
|---|---|
| D1–D5 自由找茬 | 房间中五个编号热点；帘子、墙画、橱柜、入口门、茶几 |
| 多步物件检查 | 局部检查弹窗按旧模型步骤推进；未完成不能在 Phone 记录 |
| 唯一工具 Inspection Phone | 底部按钮；游戏内承诺/扣款与现场信息并排，完成后记录证据 |
| 五项扣款/证据反击 | 至少一证据即可提前进入；选择扣款和证据卡一一匹配，正确每项返虚构 $100 |
| 错误和补救 | 错配不损失金额；两次错配给对应编号提示；可部分结算并回房补查 |
| 全额结算 | 五张证据匹配后显示 `$500 / $500`，可同身份重玩或换身份 |
| 提示/输入/声音 | 两级主动提示、20 秒热点轻提示/40 秒位置提示、键盘 1–5/Esc/Tab、触屏、声音切换 |
| 匿名事件 | 仅本地 `localStorage` 最多 300 条，可手动导出 JSON；无服务端上传 |

房东线复用同样的房间与五处事实，交互解释为“自查 → Phone 记录 → 核对并纠正扣款 → 退还押金”。角色、目标、台词与结局分别显示，未新增第三身份。
